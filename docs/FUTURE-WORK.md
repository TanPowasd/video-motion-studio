# 后续功能与优先级

按质量、自由度、外部 agent 使用优先排序。这是待实现/待深化清单，不是已完成能力或日历承诺。已有关键帧、动作模板、基础检查/修复、时间效果、解析粒子和网格/局部采样变形不重复作为新功能。

| 1 | P0 | 特效节点图深化 | 已交付代码/JSON/MCP 的多输入、分支、合成、参数连接与嵌套；后续补图内时间分支、多输出、自定义像素内核、节点画布与 GPU |
| 2 | P0 | 属性驱动深化 | 已交付数字表达式/跨图层依赖、布局锚点/留边/尺寸/宽高比、SVG弧长动作及统一求值；后续补历史属性采样、跨场景引用和更完整布局求解器 |
| 3 | P0 | 长视频分镜编排 | 镜头清单、章节、场景时长、素材及配音绑定，跨场景原子候选和总时间轴验证 |
| 4 | P0 | 跨场景质量检查 | 全片抽样策略、遮罩后像素证据、对象定位、关键转场相邻帧与声音同步报告 |
