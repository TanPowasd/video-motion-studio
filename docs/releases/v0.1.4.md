# Vmotion 0.1.4 · 画布指令、异构渲染、PPT 演示与网络远程协调

开源预览版，同步这一批画布协同、高性能渲染、演示文稿与多机远程协调能力。

- **画布指令与遮罩接单（Canvas Inbox & MCP Sampling）**：在画布选中图层或用画笔涂抹遮罩区域并填写修改诉求，Vmotion 自动打包节点属性、源码行号、交并比命中图层（`hitNodes`）及可选截图写入 `.vmotion/requests/`；外部 AI 可通过 `inbox_wait / inbox_claim / inbox_ask / inbox_done` 主动接单，亦支持在客户端宣告 `sampling` 能力时由 Vmotion 主动推送请求并在应用内完成结构化追问。
- **GPU / CPU 异构协同渲染**：自动评估轨道与场景的 GPU/CPU 算子亲和度，新增 `schedule: serial | auto | split-tracks | split-scenes` 分轨并行与分场景流水渲染策略，保证确定性零像素漂移（`maxDiff === 0`）并输出 `heterogeneous` 性能取证报告。
- **PPT 制作、导入与 AI 批量改稿**：支持 `.pptx`（OpenXML ZIP）确定性导入与无损媒体/版式往返导出，内置 10 套演示版式模板、讲稿备注自动配时，以及 `slides_inspect / slides_import / slides_plan` 与 `vmotion slides` CLI，支持拆页、换版式、插槽同步与单步原子撤销。
- **网络远程协调（Remote Coordination）**：支持多机/多人与外部 AI 跨网络协同同一工程，提供 `editor` / `viewer` 双角色常量时间 Bearer 鉴权、带 TTL 租约的细粒度作用域锁（`project` / `scene:<id>` / `sequence:<id>` / `file:<path>`）、稳定 ID 三路合并（`mergeJson` / `mergeText`）与冲突显式暂存、增量二进制素材 SHA-256 同步、远程帧预览与远程渲染回传，以及 `vmotion mcp --remote <url>` 零本地工程直连模式。

Windows 10/11 x64：完整解压 `Vmotion-Windows-x64-Portable.zip` 后运行 `Vmotion.exe`。无需单独安装 Node.js 或 FFmpeg。

人通过 UI 编辑，外部 AI 通过文件、CLI 或 MCP 操作同一工程；程序不调用 AI 模型。

发布前验证：类型检查、原生模块构建、前端与服务端构建、131 个测试文件和 730 项测试全部通过。便携版真实 MCP 契约与上下文预算、桌面端隔离交互与主题恢复、网络远程协同与异构渲染、PPT 导入导出及中文空格路径隔离导出均通过验收。

源码采用 Apache-2.0，第三方依赖保留各自许可。当前发布为预览版；AU/macOS 尚未实机验收。
