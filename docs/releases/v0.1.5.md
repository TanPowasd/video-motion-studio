# Vmotion 0.1.5 · 远程连接与创建主机界面、IPv6 双栈协同与运行时加固

开源预览版，补齐软件内网络远程协调图形界面，并同步 IPv6 双栈协同与捆绑运行时加固。

- **创建远程主机界面（Studio Host UI）**：在已打开工程顶部栏新增「远程协作」入口（及 `⋯` 菜单项），可直接在桌面端启动独立的远程协调服务，支持 `::` 双栈（IPv4+IPv6）、`0.0.0.0`、`127.0.0.1` 或指定网卡绑定与自定义/自动分配端口；界面提供多网卡连接地址选择、默认脱敏防录屏泄露的 `Editor` / `Viewer` 令牌展示、一键复制 CLI 克隆命令与跨设备 Remote MCP 配置、在线协作者状态及主机侧作用域锁强制释放。本机 Studio 窗口始终保持在独立 `127.0.0.1` 回环服务运行，切换工程或退出时自动释放外部监听端口。
- **连接远程项目与协同面板（Remote Clone & Sync UI）**：项目首页新增「连接远程项目」入口，支持输入地址与令牌先「测试连接」预检远端工程信息与权限，再一键克隆工程及 `assets/` 素材并直接打开（含非空目录保护与可选本机 `.vmotion/remote/auth.json` 凭据保存）；工程内支持一键双向三路同步（`sync` / `pull` / `push`）、按场景/序列/全工程申请租约锁，以及借用远程主机算力渲染 MP4/PNG/WAV 并经 SHA-256 校验取回本地 `exports/`。
- **IPv6 与双栈网络支持**：远程协调服务端与客户端全面支持 IPv6 字面量、`[::]` 双栈监听、`--ipv6-only` 开关及多网卡可达 URL 自动枚举（自动跳过不支持 URL zone id 的链路本地地址）。
- **运行时镜像与跟踪测试加固**：固定捆绑 FFmpeg `n8.1.3-25` 仓库镜像与多源回退，跟踪测试统一使用内置运行时 FFmpeg 与确定性编码夹具，消除宿主机 PATH 依赖。

Windows 10/11 x64：完整解压 `Vmotion-Windows-x64-Portable.zip` 后运行 `Vmotion.exe`。无需单独安装 Node.js 或 FFmpeg。

人通过 UI 编辑，外部 AI 通过文件、CLI 或 MCP 操作同一工程；程序不调用 AI 模型。

发布前验证：类型检查、前端与服务端构建、快速与远程协调集成测试、便携版真实 MCP 契约与上下文预算、桌面端无头交互验收（创建主机、探测连接、克隆工程与端口回收）及中文空格路径隔离导出全部通过。

源码采用 Apache-2.0，第三方依赖保留各自许可。当前发布为预览版；AU/macOS 尚未实机验收。
