Windows GPU 后端遵循统一帧/图层接口，计划由 Skia Direct3D 实现。目前运行信息明确返回 `gpu: false`；不会将 CPU 绘制标为 GPU 加速。

当前主线已转为 AE 级创作能力与外部 agent 工作流。已新增解析弹簧/循环/错峰、轨迹/点形变、整体合成与正确遮罩、渐变/文字入场/有序效果栈、亮部发光、种子粒子/残影、2.5D 相机投影及时间采样运动模糊。`frame_sample` 与接口指南为 agent 提供动态检查反馈。完整对照见 `AE-CAPABILITIES.md`，这些增量不表示已达到全部 AE 功能。

最新批次同时交付属性表达式、声明布局约束与曲线路径，统一渲染/选框/动画检查求值；多场景/代码生成内容可通过 drivers_plan 共用候选和一次撤销。批次细节见 PROPERTY-DRIVERS.md。

声音制作批次交付可编辑 JSON 编曲、合成/FM/鼓组、磁盘分页采样/带限变调、自动化、声音资源内部总线和混音处理、MIDI及准确候选试听，已接主时间轴和素材库。场景/序列声音路由与专业响度仍需深化。细节见 SOUND-MUSIC.md。按最新用户偏好自主选择相关功能批次，统一测试后提交。

完成 P1 前应在参考机器和集成 GPU 机器各执行一轮真实长片测试，记录性能、峰值 RAM/显存、缓存增长、音画误差、取消与恢复行为。CPU/GPU 视觉回归需要等 GPU 后端实现后执行。

最新方向为广度、高性能与优化，避免持续深挖单个子系统。本批扩展通用场景转场/隔离合成，优化组件实际依赖编译、JSON 类型缓存与临时画布复用，提供 Agent 真实性能取证；音频仅收敛已实现总线/侧链/响度增量。细节见 PERFORMANCE-TRANSITIONS.md，不替代正式实时/4K/长片验收。

后续批次已接通分镜/章节/配音的稳定 JSON 编排与完整序列质量抽样，默认短候选和分页；RGBA 无损桌面预览绕过 PNG 编解码，同时保留旧 PNG 证据路径与过期版本过滤。详见 STORYBOARD-PREVIEW.md；远程带宽、GPU/共享纹理和长片正式性能验收仍需继续。

视觉批次扩展程序化纹理/图层置换/渐变映射/多级辉光/径向光束以及九组可编辑图模板，同时加入领域/光束保守区域计算与性能计数。限定区域和全画布基线像素一致；CPU 复杂例子仍需性能深化，不宣称实时。详见 VISUAL-FIELDS.md。
