# After Effects 创作能力对照

目标：自有工程格式、外部 agent 可编程创作与功能对标。这里记录真实状态，不以 SDK 接口预留作为完成标准。

| 能力 | 当前实现 | 剩余工作与验收 |
|---|---|---|
| 图层与合成 | 层级、整体透明度、混合、效果栈、Alpha/亮度/反向遮罩与羽化，组/组件/场景引用独立编辑、生成结构/覆盖、共享场景预合成、源尺寸/相机与实例覆盖、依赖查询/实例重置/视觉内容时间映射 | 引用背景像素审计、完整合成管理与更多路径工具 |
| 时间与表达式 | 帧时钟、关键帧、贝塞尔时间曲线与基础曲线编辑器、解析弹簧、循环、错峰、效果/组件参数关键帧、视频/组件/场景内容变速/倒放/冻结/循环/重映射与祖先时钟、自有 TS 表达式 | 更完整速度/空间曲线工具、表达式控制器、声音与光流时间重映射 |
| 文字动画 | 中文、字素/词分批入场、原生测量、描边、渐变与整层效果 | 范围/表达式选择器、段落工具、路径文字、逐字全部属性控制 |
| 形状动画 | SVG 路径、渐变、点插值/折线重采样、运动轨迹、布尔运算、简化/圆角/实线转轮廓、环绕裁切、虚线/端点/拐角、同父级路径快照、线性/网格/放射图层重复器、仿射矩阵与生成结构覆盖 | 任意曲线拓扑重采样、逐轮廓裁切、虚线转轮廓、路径控制点编辑、沿任意曲线重复、原生形状算子栈、更多形状算子 |
| 特效与色彩 | 模糊、发光、阴影、亮度/对比度/饱和度/色相、Levels/Curves、3D LUT、颜色抠像、暗角、颗粒、程序化位移/像素化、局部波形/旋转/膨胀/RGB分离/擦除、网格与透视 UV、推移/旋转/膨胀笔刷场 | 多输入节点图、贴图置换/反馈、专业抠像边缘、色彩/HDR与GPU执行 |
| 粒子与残影 | 稳定出生ID解析粒子、范围发射、速度/重力/阻力/寿命、条纹/渐变/旋转、纯函数历史残影、逐层快门与历史图采样、线性光合成、Agent发射器计划/取证 | 碰撞、力场、流体、体积/贴图粒子、父级/相机世界快门与视频光流 |
| 镜头与空间 | 矩阵/层级/相机、视锥裁剪、Rust 深度与抗锯齿、形体/函数曲面/OBJ/JSON 复用、平面/平滑/逆转置法线、GGX 金属度/粗糙度、方向/点光、自发光/曝光/SDR 色调映射、agent 材质候选与取证 | 贴图/IBL/阴影/透明材质、glTF/骨骼/动画资源、GPU、景深 |
| 动态反馈 | 单帧截图、多帧接触表、结构化诊断、文字布局/遮挡几何提示、采样位移/突跳报告、标注图片与短预览导出 | 完整像素可见性/视觉理解、旋转/缩放运动检查、代理预览策略 |
| 媒体与声音 | 解码、轨道、多选链接、分割/裁切/滑移/波纹删除、入出点范围、锁定、BPM标记、SRT/VTT字幕、保留淡化与变速声音相位、混音/波形、频段驱动、分段声音预览、电平、代理、检查点导出 | 场景内声音路由、专业总线、源监视器、自动代理、专业镜头管理与更广泛实时媒体管线 |
| 跟踪与修复 | 尚未实现 | 点/平面/相机跟踪、稳定、转描、抠像和修复的完整工作流 |
| 扩展生态 | TS 组件、Schema、CLI与MCP | 注册效果与图形后端、公开插件 ABI、资源与模板发布接口 |

不要求 .aep/.aex 兼容。每个新模块都需要静态/动态画面、随机帧访问、预览/导出一致性与性能测试后更新状态。

后续功能按优先级汇总在 [FUTURE-WORK.md](FUTURE-WORK.md)；当前时间/粒子效果的边界与预算见 [TEMPORAL-PARTICLES.md](TEMPORAL-PARTICLES.md)。
